First npm release of the packages behind Tencil's daemon: `@tencil/protocol` (wire schemas and the `Provider` interface), `@tencil/bridge` (pins, prompt rendering and provider wiring, with storage and provider creation injectable) and `@tencil/testing` (a fake provider, a fake T3 Code server and a fake Claude Agent SDK).
