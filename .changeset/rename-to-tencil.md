Fixhere is now Tencil: `npx tencil`, `tencil/react` (`<Tencil />`), `tencil/vite` and tencil.dev. The first `tencil` command moves a Fixhere install over: pins, pairing and settings, its login service and running daemon. In a project, `npx tencil` rewrites the `fixhere/react` or `fixhere/vite` import and swaps the `fixhere` package for `tencil`.
